ShortsTool

ShortsTool is a personal desktop tool. Its only user is the owner of the accounts it posts to (YouTube channel Litvinchik, TikTok @litvinchik_, Instagram @litvinchikl_). It uploads the owner's own short gaming videos to the owner's own accounts and schedules their publishing through the official APIs: YouTube Data API, TikTok Content Posting API and Instagram API with Instagram Login.
